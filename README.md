A Jellyfin plugin for managing Jellyfin users via groups. It manages **Permissions**, **Password Validation**, **User Expiry**, **User Inactivity**, **Session Cleanup**, and **Invite Links**, applying each to every member of a group.

<br clear="left">

## Documentation

Installation, every feature, and uninstalling safely are covered in the **[User Management documentation](https://jpkribs.github.io/jellyfin-plugin-usermanagement/)**.
